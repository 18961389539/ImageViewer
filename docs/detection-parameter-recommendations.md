# 检测参数推荐

加载图像，选择直线卡尺、双边卡尺、圆形或圆弧卡尺、Blob 分析 ROI，然后右键选择“当前对象 → 推荐检测参数…”，也可以从“测量 → 边缘检测”进入。菜单搜索支持“推荐参数”和“自动调参”。锁定对象需要先解锁。

工具在当前 ROI 中分析局部对比度、噪声和边缘方向，生成一组参数建议，并使用现有检测器分别试运行当前参数和建议参数。对话框显示参数前后值、依据、图像裁剪和检测点，以及评分、拟合残差和有效采样比例。

卡尺可推荐搜索范围、采样数量、平均宽度、平滑 Sigma、梯度阈值，以及证据明确时的单边极性。增加采样数量时同步提高最少有效数量，保持原有最低有效比例。Blob 可建议启用 Otsu 自动阈值；明暗目标和最小面积保留。

质量门限、公差、标定、几何位置、双边间隙先验和拟合损失配置不会自动改变。低对比度、越界、过大的分析区域、采样不足或建议结果明显退化时，不允许应用。单张图像的试检测通过不代表精度、重复性或整个生产过程已经验证。

点击“应用建议”才会修改当前 ROI，参数和试检测结果作为一次可撤销操作保存。取消或关闭对话框不修改对象。若分析期间图像、ROI、标定或项目质量配置发生变化，旧建议会被拒绝，需要重新生成。建议生成在后台执行，卸载或释放控件会取消任务。

代码接口：`ImageViewer.RecommendDetectionParametersAsync()`。推荐只基于当前图像，不需要外部 AI 服务。
