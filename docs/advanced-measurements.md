# 高级测量

图像右键菜单的“分析与导出 → 高级测量”和工具栏的“高级测量”均可打开测量面板。面板是独立窗口，打开期间可以继续在图像上绘制和编辑来源 ROI。

## 操作流程

1. 打开图像并完成像素/物理尺寸标定；未标定时使用 `px`。
2. 在图像上建立点、线、圆、折线或多边形来源。自动形状测量使用矩形或 Blob ROI 作为搜索区域。
3. 在高级测量中选工具，填写名称，并按下表顺序添加来源。列表中的上移/下移控制操作数顺序。
4. 点击“保存测量项”。选中已保存项后可修改参数并再次保存；“新建测量项”清空编辑器。
5. 查看结果、方法、限值判定、几何预览和采样曲线。编辑来源 ROI 后面板会重新计算；更改标定或图像后可点击“重新计算”。
6. 保存 ROI、会话或测量配方会一并保存关联定义。导出按钮生成 CSV 和同名 `.metadata.json`。

## 工具与来源

| 工具 | 来源与参数 | 输出 |
| --- | --- | --- |
| 中点 | 两个点或圆心 | 构造点，可作为后续来源 |
| 直线交点 | 两条线 | 无限直线交点；平行或重合时失败 |
| 垂足与点线距离 | 点、线 | 垂足与距离 |
| 平行线中心线 | 两条平行线段 | 构造中心线 |
| 角平分线 | 顶点、第一射线点、第二射线点 | 内角平分线与夹角 |
| 对象最短边界距离 | 两条有限线段、两个圆、线段与圆或两条折线 | 最短距离及对应边界点 |
| 指定方向的中心投影距离 | 两个点/圆心；参数为方向角（度），也可添加第三条线作为方向 | 有符号投影距离 |
| 直线形状偏差 | 至少三个实际检测边缘点，或手动折线样本 | 正交最小二乘拟合的垂直残差峰谷差 |
| 圆形径向偏差 | 成功检测的圆卡尺边缘点，或轮廓样本 | 代数最小二乘圆拟合的径向残差峰谷差 |
| 自动矩形外接尺寸 | 矩形/Blob 搜索 ROI，或闭合多边形 | 最小面积外接矩形的长边、短边、面积、方向 |
| 槽孔/胶囊拟合 | 矩形/Blob 搜索 ROI，或闭合多边形 | 总长、宽度、方向及最大残差；不符合胶囊形状时失败 |
| 连续间隙/厚度 | 源折线、对边折线；参数为物理采样间距 | 法线上的最近对边间距、最小/最大/平均值、标准差与曲线 |
| 二维位置偏差 | 点或圆心，填写理论 X/Y | 位置偏移与两倍偏移；可选择工件坐标下的理论物理位置 |
| 孔阵列/周期节距 | 按顺序添加点或圆 | 相邻中心间距及统计 |
| 孔阵列分布圆 | 至少三个不共线点或圆心 | 分布圆半径、直径与径向 RMS |
| 轮廓偏差比较 | 被测折线、参考折线；参数非负为有符号，负数为绝对值 | 被测顶点到参考有限线段的最近距离与偏差序列 |
| 轮廓/Blob 形状指标 | 矩形/Blob 搜索 ROI，或闭合多边形 | 面积、周长、Feret 径、长宽比、面积周长圆形度、孔洞率 |
| 图像周期条纹/引脚节距 | 一条距离测量线，横穿重复结构；参数负数选择暗条纹，否则选择亮条纹 | 自动阈值分割完整条纹，计算相邻条纹中心节距 |

构造结果通过稳定 ID 引用来源。构造点、中心线、分布圆等可以继续作为其他测量的来源；删除被引用来源后相关项显示失败。关联中出现循环、重复 ID 或无效数据时拒绝计算。

## 测量定义与限值

- 限值只比较结果列表中的**首项指标**，单位使用该指标的单位。长度、面积、角度和比值有不同单位。
- 物理测量先校正点坐标，再按像素尺寸换算。无有效标定或检测结果时显示失败；手动画出的理想线和圆不能作为实际形状误差样本。
- 直线形状偏差和圆形径向偏差采用明确的拟合方法，不是最小区域法的标准形位公差评定。面积周长“圆形度”是形状比值，与圆形径向偏差是不同指标。
- 自动矩形输出的是外接尺寸。槽孔使用 PCA 方向与胶囊轮廓残差门控，需检查拟合预览与检测质量。
- 搜索区域默认用 Otsu 自动阈值检测亮目标；Blob ROI 可设置亮暗极性、阈值和最小面积。使用最大连通区域，拒绝被搜索区域或图像边缘裁剪的目标。图像轮廓采用像素边界，不能将其视为亚像素检测。
- 条纹节距使用线段灰度剖面和阈值插值；忽略被线段端点截断的条纹。它提供重复结构间距，不自动识别螺纹规格或齿轮参数。
- 搜索区最多 400 万像素，轮廓/测量来源最多 4096 个顶点，间隙最多 4096 个采样点，面板中的周期测量线最多 4095 px；超过限制会提示缩小区域或调整阈值。一个工作区最多 256 项关联测量，每项最多 64 个来源，关联层级最多 64 层。

## 保存与导出

新增持久化字段是 ROI 的 `MeasurementId` 与 `AdvancedMeasurements`。旧文件缺少字段时生成来源 ID，不影响原有 ROI 加载。ROI 克隆和撤销重做保留关联定义；配方对齐会变换图像坐标下的理论位置，工件坐标下的理论物理位置保持不变。

基准对齐时，中心投影距离的手填方向角随 ROI 一起旋转。若选择了第三条线作为方向，则使用对齐后的有向线段。来源顺序和限值保持不变。

高级测量的 CSV 包含每项指标、失败原因和采样序列；元数据包含完整 ROI 文档、关联定义、标定、工件坐标系、方法、结果及 CSV 哈希。图像存在时记录当前内存像素缓冲区的 SHA-256、尺寸和格式，区分加载后的图像与磁盘路径。两个文件作为一组写出，后续写入失败时回滚已有目标。

导出开始时固定当前图像、ROI 和标定，再在后台计算结果及图像哈希；期间继续编辑不会改变这次导出的内容。自定义 ROI 的元数据使用当前查看器的插件注册表。导出期间按钮暂时禁用，关闭高级测量窗口会取消尚未完成的导出；取消时保留原有目标文件。
