# 右键菜单

在图像空白处右键打开通用菜单；在 ROI 上右键会选中指针命中的对象，并显示该对象名称、类型与相关操作。对象属性使用菜单顶部的“编辑属性…”入口。

## 常用操作与分组

- 打开图像、保存会话、撤销/重做、适应窗口、实际尺寸、重置视图和当前对象属性位于第一层。
- “测量”按基础尺寸、边缘检测、几何关系与构造、形状与轮廓、位置/阵列/节距分组。新增的 18 项高级测量均有独立入口；点击后打开面板并预选对应工具，适用时带入所选 ROI。
- “推荐检测参数…”位于边缘检测分组及支持检测的当前对象菜单，比较当前与建议参数的试检测结果后可选择应用，支持撤销。参见[检测参数推荐](detection-parameter-recommendations.md)。
- “图像显示”包含显示建议、伪彩、直方图和灰度剖面；“性能设置”包含金字塔、分块、GPU、预取和缓存。
- 常用但条件尚不满足的操作保持灰色，鼠标停留可查看缺少的图像、来源或检测条件。

## 对象与节点操作

“当前对象”菜单按所选 ROI 提供相关测量和设置，例如圆的圆心距/边界距离、路径的间隙/轮廓比较、矩形搜索区域的矩形/槽孔/Blob 分析。锁定来源仍可用于分析；节点编辑受锁定状态约束。

右键命中折线或多边形节点只选定目标，**不会立即删除节点**。点击“当前对象 → 删除此节点”才执行删除，支持撤销和重做。折线至少保留 2 个节点，多边形至少保留 3 个节点。对象、节点或几何在菜单打开后发生变化时，旧删除命令会拒绝执行，需重新右键选定目标。

## 搜索

打开菜单后可直接输入命令名称、别名或快捷键，例如“孔径”“缝宽”“槽孔”“直线度”“Ctrl+Z”。空格分隔的多个关键词需要同时匹配。

匹配命令以单独行直接显示在当前菜单，并带有完整所属路径。无需逐级打开子菜单；禁用结果仍显示原因且不能执行。

- `↓` 聚焦第一个可执行结果。
- 只有一个可执行结果时，`Enter` 执行该命令。
- `Esc` 先清空搜索，再次按下关闭菜单。
- 清空搜索恢复原来的菜单结构及可见性。

相关算法的定义和适用范围见 [高级测量说明](advanced-measurements.md)。
