Formatting contracts:
- DetectionRecommendationTrialMetrics: score, residual, valid sample count, total sample count, plotted point count.
- DetectionRecommendationPointTooltip: image-space x and y coordinates.
- Polarity and Boolean values use the RecommendationValue* keys. Numeric parameter values remain in their source string format.

Proposal failure and trial status strings use keys supplied by the recommendation engine, including its baseline-unavailable,
no-change, unsupported-ROI, clipped-ROI, insufficient-support, low-contrast, ambiguous-polarity, and candidate-worsened keys.
